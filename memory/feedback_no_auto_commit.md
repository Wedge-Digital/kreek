metadata:
  type: feedback
---

Ne jamais créer de commit sans que l'utilisateur le demande explicitement.

**Why:** L'utilisateur veut contrôler quand les commits sont créés.

**How to apply:** Terminer le travail d'implémentation sans committer. Attendre une instruction du type "commit", "committe ça", "git commit" avant de créer un commit.
